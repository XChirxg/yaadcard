# Product Images Folder

Place your product images in this folder. The storefront will automatically look for them using the filenames listed below.

## Filename Mapping
For the default products, name your image files exactly as follows:

| Product Name | Expected Filename |
| :--- | :--- |
| **47 Laws of Powers** | `47_laws_of_powers.jpg` |
| **Biology** | `biology.jpg` |
| **Business Finance** | `business_finance.jpg` |
| **Economics** | `economics.jpg` |
| **Pharmacology** | `pharmacology.jpg` |
| **Philosophy** | `philosophy.jpg` |
| **Physics Formulas** | `physics_formulas.jpg` |
| **Indian Polity** | `indian_polity.jpg` |
| **Psychology** | `psychology.jpg` |
| **Statistics** | `statistics.jpg` |
| **Himachal Collections** | `himachal_collections.jpg` |
| **Custom Flashcards** | `custom_flashcards.jpg` |

## Image Recommendations
- **Format**: `.jpg` or `.png`
- **Aspect Ratio**: `5:7` (matches standard poker card dimensions)
- **Size**: For fast page loading, keep image sizes under `300 KB` (recommended dimensions: `500x700` pixels).

> [!NOTE]
> If any image is missing, the website will display a beautiful, colored CSS-based tuck-box placeholder so the storefront always looks polished and premium!
